Proyecto Food store

# Breve descripcion

El proyecto es una pagina web con una Food Store con su respectivo Catalogo, Carrito y un Login y Register para un manejo de usuarios y un pequeño panel de admin, que solo puede ser accedido por los usuarios con el rol de admin. En el catalogo tenemos un form con un input para buscar productos especificos o sino un aside con una lista de categorias como pizzas, hamburguesas o bebidas.

# Como ejecutarlo
Para ejecutar el proyecto debemos posicionarnos en la carpeta proteger_rutas y con pnpm installado, tirar desde la terminar el comando:
    1. pnpm i
    2. y luego pnpm dev
Con esto se levantara el proyecto en http://localhost:5173/
